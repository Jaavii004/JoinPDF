FAQ

Preguntas frecuentes

¿Funciona sin internet?
+
Sí, completamente offline. Unir PDF no requiere conexión a internet en ningún momento. Tus archivos se procesan localmente en tu ordenador y nunca se envían a ningún servidor externo. Ideal para documentos confidenciales.
¿Es seguro instalar el .exe?
+
Totalmente. El instalador está verificado en VirusTotal (0 detecciones) y el código fuente está disponible en GitHub para que cualquiera pueda revisarlo. No contiene adware, spyware ni software no deseado de ningún tipo.
¿Es realmente gratis?
+
Sí, completamente gratis. Sin versión premium, sin suscripción, sin publicidad. Es un proyecto de software libre. Puedes usarlo en tu casa, en tu empresa o en todos los ordenadores que quieras.
¿Cuántos PDFs puedo unir a la vez?
+
No hay límite. Puedes unir 2 o 200 archivos PDF en una sola operación. El único límite es la memoria RAM de tu ordenador. Para uso normal de oficina, funciona perfectamente con decenas de archivos.
¿Se pierde calidad al unir PDFs?
+
No. El motor PyPDF realiza una unión sin recompresión, lo que significa que las imágenes, texto y formato del PDF original se conservan al 100%. El archivo resultante tiene exactamente la misma calidad que los originales.
¿Es realmente compatible con Windows 11?
+
Sí. JoinPDF es totalmente compatible con Windows 10 y Windows 11. Se integra perfectamente en el Explorador de Archivos, incluyendo el nuevo menú contextual de Windows 11.
